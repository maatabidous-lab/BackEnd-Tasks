المطلوب منك

🎯 اعمل ده في server.js

  1. اعمل npm install express واعمل سيرفر بـ app.listen(3000)
  2. اعمل app.use(express.json()) عشان تقرا الـ Body
  3. اعمل app.get('/api/employees') يرجع كل الموظفين
  4. اعمل app.post('/api/employees') يضيف موظف جديد
  5. اعمل app.get('/api/employees/:id') يجيب موظف واحد
  6. اعمل Middleware يطبع Method + URL + Time لكل طلب
